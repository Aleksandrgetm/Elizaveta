# Второй дизайн-проход — личный съёмочный дневник

Текущая первая версия не утверждена. Этот проход полностью заменяет её визуальную систему; UI/UX skill не применяется. Исходные фото и content.js сохраняются. Репозиторий и Sites identity прежние.

## Что отменяется

Старая Cormorant/Manrope/Caveat система, крупное имя слева + портрет справа, одинаковые секционные линейки, декоративные звёзды, круглые stickers, повторяющиеся поляроиды, фото + список услуг и единый fade-up для всех секций. Предыдущая версия остаётся только в Git history.

## Art direction

Личный съёмочный дневник: у каждого физического элемента роль. Плёнка связывает обложку и знакомство. Скреплённые листы дают ощущение личной записи. Винил — меню с дорожками, бумажная обложка и поворотный диск. Услуги — заметки вокруг центрального кадра. Галерея — контактный лист, фотографии без рамки, негатив и одна бумажная карточка. Контакты завершают мотив письма.

Палитра: тёплая бумага #fbf6ea, пыльный розовый #ecc7ce, тёмное вино #652b3e, чернильный шоколад #291c18. Никаких звёзд, случайных кружков или sparkles. Плёнка, бумажный скотч и конверт созданы CSS специально для проекта, как явно разрешено новым заданием.

## Кириллическая типографика

Prata — контрастная антиква для имени и заголовков, Golos Text — русский текст и интерфейс, Marck Script — короткие рукописные заметки. Не более трёх семейств. Основной текст 16 px, названия видео минимум 12 px на 320 px. Регистр и размер определяются ролью; англоязычные надписи декоративные.

## Motion

GSAP + ScrollTrigger, без scroll-jacking. Intro: закрытый конверт прилетает, клапан открывается, карточка выезжает из кармана, появляется подпись, сцена раскрывается в hero. 3.6 секунды, пропуск, один раз за сессию, reduced motion отключает.

Hero: фотографии собираются из слоёв; имя раскрывается маской. About: выезд бумаги и медленное смещение плёнки. Vinyl: entrance scale + scroll-driven rotation 150°; labels неподвижны, hover/focus слегка приподнимает диск. Niches: строки раскрываются по очереди. Work: последовательное появление рядов и тактильное нажатие; viewer разворачивается из положения превью. Services: центральный кадр + разъезжающиеся заметки. Gallery: проявление фотографий, разные небольшие глубины. Contact: раскрытие сложенного листа.

На mobile меньше амплитуды, тяжёлого pinning нет. Анимации transform/opacity; clip-path используется только для коротких reveals. gsap.matchMedia автоматически снимает motion при reduced motion. Контент виден без GSAP.
