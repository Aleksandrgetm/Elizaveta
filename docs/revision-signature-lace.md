# Розовая обложка и карта направлений

По правкам пользователя от 3 октября 2026: hero получает розовый полосатый фон и точное имя «Елизавета». Тонкая рукописная надпись — оригинальный прозрачный imagegen asset; доступный текст h1 сохранён. Семейства шрифтов сайта не меняются.

«Мои направления» заменены картой: реальный портрет Лизы в ажурной овальной рамке, пять овалов с фото и короткими описаниями. Desktop: портрет в центре, четыре направления по сторонам и lifestyle снизу; phone: два направления сверху, портрет по центру, остальные снизу. Lifestyle включает товары для дома и повседневной жизни. Wellness дополнен по новому референсу.

Одна гранёная звезда возле пластинки — собственный SVG по новому прямому запросу пользователя (прежний запрет на звёзды этим запросом изменён). Вращение диска сохранено.

Новые production assets:
- `dist/assets/lace-frame.webp`: original imagegen ivory paper lace oval frame with dusty pink satin bow, transparent center/outer area; 900×1200, 304 KB. Сгенерирован по мотивам референса, фотография Лизы не изменена. Изображение салфетки с водяным знаком не использовалось в production.
- `dist/assets/elizaveta-signature.webp`: original imagegen exact Cyrillic «Елизавета», thin chocolate brown flowing script, transparent background; 2161×728, 139 KB. Буквы проверены визуально.

Изменены только hero, направления, звезда и связанные анимации. Дополнительно исправлен переход по прямому hash-адресу к динамически добавляемым секциям.

Проверка: `npm run check` проходит; просмотрены hero 390/768, направления 320/390/1440, винил 320. Переполнение текста в овалах не обнаружено, documentElement.scrollWidth совпадает с viewport. Консоль без ошибок/предупреждений. Сохранён снимок `docs/screenshots/v3-directions.png`.
