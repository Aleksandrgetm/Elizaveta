# Рисованный декор и анимация имени

- «Елизавета»: исходная каллиграфия сохранена. SVG mask с девятью последовательными pen trajectories; GSAP рисует stroke-dashoffset. Нет typewriter/wipe подмены. Завершение раскрывает исходное изображение полностью. При reduced motion и без GSAP имя сразу видно целиком.
- Плёнка: увеличена высота кадров (160 px mobile, 279 px desktop), исправлен stacking context: фон виниловой секции больше не перекрывает нижнюю половину плёнки.
- Подпись «каждый кадр — с настроением» удалена. Секции Services и Gallery удалены из рендера и навигации, а их GSAP-анимации удалены. Исходные фото и данные сохранены. Контакты стали секцией 05.
- `dist/assets/doodles.svg`: авторский SVG sprite с 8 вариантами (3 звезды, 2 сердца, росчерк, стрелка, абстрактная петля), нарисован вручную координатами. Не emoji, не Unicode и не icon library.
- `dist/decorations.js`: reusable Decoration/StrawberryMascot и централизованная карта размещений. Декор aria-hidden/pointer-events:none; размеры и позиции отдельно настроены для mobile. Три вспомогательных элемента скрыты на телефонах.
- Мягкие одноразовые повороты/scale, сердце с лёгким overshoot, stroke draw-on для стрелки; нет бесконечных мигающих loops. GSAP matchMedia отключает их при reduced motion.
- `dist/assets/strawberry.webp`: оригинальный персонаж, созданный imagegen по собственной интерпретации пользователя. Blush berry body, sage leaves, tiny brown eyes/smile, cream seeds, small feet; не копия присланной куклы. 360×380, прозрачность, ~9 KB. Размещён один раз возле Lifestyle; маленький peek при появлении.

Проверка: npm run check (включая decorations.js и reduced-motion ветвь), отсутствие удалённых секций и ссылок на них, без ошибок консоли. Анимация имени проверена кадрами около 0.9/2.4/3.7 секунд. Viewport-проверка 320/375/390/430/768/1024/1440 px: горизонтального переполнения нет; ключевые композиции просмотрены вручную. Физический iPhone не использовался.
